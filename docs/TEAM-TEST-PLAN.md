# Team Test Plan ก่อนแข่งขัน

ทำเครื่องหมายผ่านเมื่อทดสอบจริงบนเครื่องที่จะใช้แข่งขันแล้วเท่านั้น

## Frontend
- [ ] เปิด `/` แล้วไปหน้า Login
- [ ] Login สำเร็จแล้วไป Dashboard ตาม Role
- [ ] ผู้ใช้ Role อื่นเปิด URL ที่ไม่มีสิทธิ์ไม่ได้
- [ ] ปุ่มเพิ่ม/แก้ไข/ปิดใช้งาน แสดงผลตรงกับฐานข้อมูล
- [ ] รีเฟรชหน้าแล้วข้อมูลยังอยู่
- [ ] แสดงข้อความเมื่อ API สำเร็จและเมื่อผิดพลาด

## Backend
- [ ] ไม่มี Token เรียก API ที่ต้อง Login ไม่ได้
- [ ] Role ไม่ถูกต้องได้รับ 403
- [ ] ตรวจสอบข้อมูลที่รับจาก `req.body`
- [ ] SQL ใช้ placeholders `?`
- [ ] ทดสอบ GET / POST / PUT / DELETE ตาม Endpoint จริง
- [ ] ทดสอบ Upload/Download และตรวจสิทธิ์ไฟล์

## ระบบประเมิน
- [ ] Admin สร้างรอบประเมินได้
- [ ] Admin จัดการหัวข้อและตัวชี้วัดได้
- [ ] Admin มอบหมายผู้รับการประเมินและกรรมการได้
- [ ] ผู้รับการประเมินบันทึกคะแนน/รายละเอียด/หลักฐานได้
- [ ] ผู้รับการประเมินส่งผลได้
- [ ] กรรมการตรวจและยืนยันผลได้
- [ ] รายงานแสดงข้อมูลตรงกับฐานข้อมูล
- [ ] Backup/Restore ทำงานได้จริง

## เอกสารและผังงาน
- [ ] Flowchart ตรงกับหน้าจอและ API จริง
- [ ] System Overview แสดง Frontend, Backend, Database
- [ ] ERD แสดง PK/FK และความสัมพันธ์ถูกต้อง
- [ ] Class Diagram ตรงกับคลาสที่กำหนด
- [ ] API document มี Method, URL, Role, Body และ Response
